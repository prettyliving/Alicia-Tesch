# Alicia Tesch — Studio in Progress

Personal portfolio for Alicia Tesch, built with React, Vite and TypeScript.

## Design direction

Editorial luxury with creative, index-style navigation. Alicia's personal identity leads; Studio in Progress is the independent creative practice behind the work.

- Warm parchment, forest green, emerald and muted gold
- Playfair Display + DM Sans
- Responsive layouts and editorial typography
- Project archive with category filters and individual project pages
- About, Studio and Contact pages

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Deploy to Vercel

Import this repository into Vercel and use:
- Framework preset: Vite
- Build command: `npm run build`
- Output directory: `dist`

Project content is maintained in `src/data/projects.ts`. Keep statuses and descriptions current. Do not publish unverified results, technical choices or project outcomes as facts.

## Before launch

- Add a confirmed professional email address and update the contact page.
- Add a current resume PDF under `public/documents/`.
- Confirm social profile URLs.
- Review all project statuses and descriptions.
- Run accessibility, mobile and production-build checks.
- Connect the production domain in Vercel and verify DNS.
