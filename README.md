# Alicia Tesch | Studio in Progress

Personal portfolio for Alicia Tesch, built with React, TypeScript, and Vite.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Deployment

Configured for Vercel with the Vite preset:
- Build command: `npm run build`
- Output directory: `dist`

## Current scope

The first release establishes the personal homepage and visual direction. Project descriptions and statuses are working drafts and should be reviewed before public launch. Contact details, resume, and social profile destinations will be added once confirmed.
